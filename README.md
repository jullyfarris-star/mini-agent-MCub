# mini-agent-MCub

Модульний прототип AI-mini «Куба».

## Структура

- `config/` — конфігурація та ДНК агента
- `core/` — робочі модулі агента
- `data/knowledge/` — локальні знання для RAG
- `scripts/` — запуск демо та перевірок
- `tests/` — тести

## Запуск

```bash
python scripts/test_runner.py
```

Або:

```bash
python -m unittest discover -s tests -v
```

Це перший робочий каркас: він не підключає зовнішню модель, але вже завантажує конфігурацію, тримає контекст, шукає по локальних файлах і має запобіжники.
